# Mathematics Training Book

## Chapter 1: Algebra Fundamentals

### Variables and Expressions
- Variables: Symbols (x, y, z) representing unknown values
- Constants: Fixed numerical values
- Terms: Individual parts of an expression
- Like terms: Terms with the same variable

### Solving Linear Equations
```
Single-step: x + 5 = 12 → x = 7
Two-step: 2x + 3 = 11 → 2x = 8 → x = 4
Multi-step: 3(x + 2) = 15 → 3x + 6 = 15 → x = 3
```

### Polynomial Operations
```
Addition: (2x + 3) + (x + 5) = 3x + 8
Subtraction: (2x + 3) - (x + 5) = x - 2
Multiplication: (x + 2)(x + 3) = x² + 5x + 6
```

## Chapter 2: Quadratic Equations

### Standard Form
ax² + bx + c = 0 (where a ≠ 0)

### Solving Methods
1. **Factoring**: If x² + 5x + 6 = 0 then (x + 2)(x + 3) = 0 → x = -2 or x = -3
2. **Quadratic Formula**: x = [-b ± √(b² - 4ac)] / (2a)
3. **Completing the Square**: Rearranging to perfect square form

### Graphing
- Parabola shape (opens up if a > 0, down if a < 0)
- Vertex: Highest or lowest point
- Axis of symmetry: Vertical line through vertex
- Y-intercept: Where graph crosses y-axis (when x = 0)

## Chapter 3: Systems of Equations

### Two-Variable Systems
```
Substitution method:
y = 2x + 1
x + y = 4
→ x + (2x + 1) = 4 → x = 1, y = 3

Elimination method:
2x + y = 5
x - y = 1
→ 3x = 6 → x = 2, y = 1
```

### Solution Types
- One solution: Lines intersect at one point
- No solution: Lines are parallel
- Infinite solutions: Lines are identical

## Chapter 4: Functions

### Function Notation
f(x) = 2x + 3
- Input (independent): x
- Output (dependent): f(x)
- f(2) = 2(2) + 3 = 7

### Common Functions
```
Linear: f(x) = mx + b (straight line)
Quadratic: f(x) = ax² + bx + c (parabola)
Cubic: f(x) = ax³ + bx² + cx + d
Absolute value: f(x) = |x|
Square root: f(x) = √x
```

### Function Properties
- Domain: All possible input values
- Range: All possible output values
- Increasing/Decreasing: Direction of function
- Maximum/Minimum: Highest/lowest points

## Chapter 5: Geometry

### Basic Shapes and Formulas
```
Triangle:
  Area = (1/2) × base × height
  Perimeter = a + b + c
  
Rectangle:
  Area = length × width
  Perimeter = 2(length + width)
  
Circle:
  Area = πr²
  Circumference = 2πr or πd
  
Square:
  Area = side²
  Perimeter = 4 × side
```

### 3D Shapes
```
Cube:
  Volume = side³
  Surface Area = 6 × side²

Rectangular Prism:
  Volume = length × width × height
  Surface Area = 2(lw + lh + wh)

Sphere:
  Volume = (4/3)πr³
  Surface Area = 4πr²

Cylinder:
  Volume = πr²h
  Surface Area = 2πr² + 2πrh
```

### Angles
- Acute angle: Less than 90°
- Right angle: Exactly 90°
- Obtuse angle: Between 90° and 180°
- Straight angle: Exactly 180°
- Sum of angles in triangle: 180°
- Sum of angles in quadrilateral: 360°

## Chapter 6: Trigonometry

### Right Triangle Ratios (SOHCAHTOA)
```
sin(θ) = opposite / hypotenuse
cos(θ) = adjacent / hypotenuse
tan(θ) = opposite / adjacent
```

### Special Angles
```
30°: sin = 1/2, cos = √3/2, tan = 1/√3
45°: sin = √2/2, cos = √2/2, tan = 1
60°: sin = √3/2, cos = 1/2, tan = √3
90°: sin = 1, cos = 0
```

### Pythagorean Theorem
a² + b² = c² (for right triangles)
- Used to find missing side lengths
- Used to verify right triangles

## Chapter 7: Exponents and Logarithms

### Exponent Rules
```
Product rule: a^m × a^n = a^(m+n)
Quotient rule: a^m / a^n = a^(m-n)
Power rule: (a^m)^n = a^(m×n)
Zero exponent: a^0 = 1 (a ≠ 0)
Negative exponent: a^(-n) = 1/a^n
Fractional exponent: a^(1/n) = ⁿ√a
```

### Logarithms
```
Definition: log_a(x) = y means a^y = x
Common logarithm: log₁₀(x) = log(x)
Natural logarithm: log_e(x) = ln(x)
```

### Logarithm Rules
```
Product rule: log(a×b) = log(a) + log(b)
Quotient rule: log(a/b) = log(a) - log(b)
Power rule: log(a^n) = n × log(a)
```

## Chapter 8: Sequences and Series

### Arithmetic Sequences
- Common difference: d = a₂ - a₁
- nth term: aₙ = a₁ + (n-1)d
- Sum of n terms: Sₙ = n/2 × (2a₁ + (n-1)d)

### Geometric Sequences
- Common ratio: r = a₂ / a₁
- nth term: aₙ = a₁ × r^(n-1)
- Sum of n terms: Sₙ = a₁(1 - r^n) / (1 - r)

## Chapter 9: Calculus Concepts

### Limits
- lim(x→a) f(x) = L means f(x) approaches L as x approaches a
- Used to understand function behavior

### Derivatives
- Represents rate of change
- Notation: f'(x), dy/dx
- Power rule: d/dx(x^n) = n × x^(n-1)
- Chain rule: d/dx[f(g(x))] = f'(g(x)) × g'(x)

### Integrals
- Represents area under curve (antiderivative)
- Power rule: ∫x^n dx = x^(n+1)/(n+1) + C
- Definite integral: ∫ₐᵇ f(x)dx represents total accumulated change

## Chapter 10: Statistics and Probability

### Descriptive Statistics
```
Mean (average): Sum of values / Number of values
Median: Middle value when ordered
Mode: Most frequently occurring value
Range: Maximum - Minimum
Standard Deviation: Measure of spread
```

### Probability
```
Probability of event: P(A) = (favorable outcomes) / (total outcomes)
Addition rule: P(A or B) = P(A) + P(B) - P(A and B)
Multiplication rule: P(A and B) = P(A) × P(B|A)
Complement: P(not A) = 1 - P(A)
```

### Distributions
- Normal Distribution: Bell curve, symmetric
- Binomial Distribution: Binary outcomes over n trials
- Poisson Distribution: Number of events in fixed interval

## Chapter 11: Number Systems

### Integer Operations
```
Addition: -3 + 5 = 2
Subtraction: -3 - 5 = -8
Multiplication: -3 × 5 = -15
Division: -15 / 5 = -3
```

### Fractions
```
Simplification: 6/8 = 3/4
Addition: 1/2 + 1/3 = 3/6 + 2/6 = 5/6
Subtraction: 1/2 - 1/3 = 3/6 - 2/6 = 1/6
Multiplication: 1/2 × 1/3 = 1/6
Division: 1/2 ÷ 1/3 = 1/2 × 3/1 = 3/2
```

### Decimals and Percentages
```
Decimal to percent: 0.25 = 25%
Percent to decimal: 45% = 0.45
Percent change: (new - old) / old × 100%
Percentage of: 25% of 80 = 0.25 × 80 = 20
```

## Chapter 12: Word Problems Strategy

### Problem-Solving Steps
1. Read carefully and identify what you're looking for
2. Define variables for unknown quantities
3. Write equations based on relationships
4. Solve the equations
5. Check if answer makes sense
6. State the answer clearly

### Common Problem Types
- Distance/Rate/Time: D = R × T
- Work problems: Combined rate × time = job
- Mixture problems: Concentration × amount = substance
- Investment problems: Principal × rate × time = interest
